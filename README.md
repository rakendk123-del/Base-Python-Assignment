# Student Exam Performance Analysis

## Project Overview

This project focuses on analyzing student exam performance using Python.
The main aim is to understand the factors that are related to students'
exam scores and identify useful patterns from the dataset.

## Objectives

- Analyze student exam performance
- Identify factors related to exam scores
- Understand the relationship between study hours and performance
- Analyze the effect of stress and sleep on students
- Explore previous exam scores and current exam scores
- Visualize important patterns using different charts

## Dataset

The dataset contains information about students, their study habits,
academic performance, stress levels, sleep hours, exam difficulty,
previous exam scores and current exam scores.

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly Express

## Project Workflow

1. Data Import
2. Data Cleaning and Pre-Processing
3. Exploratory Data Analysis
4. Data Visualization
5. Findings and Insights

## Data Cleaning

The dataset was checked for missing values and duplicate records.
Missing numerical values were handled using the mean, while categorical
missing values were handled using the mode.

The dataset was also checked for duplicate records, and no duplicate
records were found.

Unnecessary columns were removed to make the dataset simpler and easier
to analyze.

## Exploratory Data Analysis

Different visualizations were created to understand the relationships
between student behaviour and exam performance.

Some of the important analyses include:

- Study Hours vs Exam Score
- Previous Exam Score vs Current Exam Score
- Exam Score Distribution
- Stress Level vs Exam Score
- Stress Level vs Questions Correct
- Sleep Hours vs Stress Level
- Break Frequency vs Exam Score
- Exam Difficulty vs Exam Score
- Correlation Heatmap
- Pass vs Fail Analysis

## Key Findings

- Students who study more generally tend to have higher exam scores.
- Previous exam scores show a positive relationship with current exam scores.
- Higher stress levels are associated with lower exam scores.
- Students with lower sleep generally tend to have higher stress levels.
- Break frequency shows very little difference in average exam scores.
- Exam scores generally decrease as exam difficulty increases.
- Questions correct has a strong relationship with exam score.

## Conclusion

This project helped me understand how data cleaning, exploratory data
analysis and visualization can be used to analyze student performance.
The analysis identified several factors that are associated with exam
performance and helped me understand the patterns present in the dataset.
